# Grille d'observation

Une grille par joueur. À remplir pendant la partie, compléter dans l'heure qui suit.

**Règle d'écriture** : noter ce qu'on **voit** et ce qu'on **entend**, pas ce qu'on en
déduit. « Regarde le relevé 15 s puis choisit » plutôt que « hésite ». Les citations
entre guillemets, mot pour mot ; une citation approximative se note `≈ « … »`.

Codes rapides :
`R` relevé regardé · `D` « Voir le détail » ouvert · `É` échelle changée ·
`A` autres personnages consultés · `M` page méthode ouverte · `S` silence > 30 s ·
`?` incompréhension · `!` émotion visible · `★` signe de déclic · `$` signe SPENT ·
`⇐` / `⇒` biais perçu (préciser le sens en toutes lettres).

## 7. Signes à repérer tout au long de la partie

Cocher, puis noter l'écran et la citation. Un seul signe ne prouve rien ; on cherche des
répétitions.

### Signes de déclic `★`

| ☐ | Signe | Écran | Citation |
|---|---|---|---|
| ☐ | Relit sa propre phrase dans un rappel et marque un temps, ou la commente | | |
| ☐ | Relie un effet vécu à une décision qu'il a prise lui-même (« c'est moi qui ai voté ça ») | | |
| ☐ | Change sa réponse à la relance **en citant** le personnage ou sa situation | | |
| ☐ | Maintient sa réponse **en reconnaissant** ce qu'elle coûte à quelqu'un | | |
| ☐ | Formule spontanément une surprise sur la façon dont une règle touche une autre personne (« je n'avais pas pensé que… ») | | |
| ☐ | Remarque qu'une même somme pèse très différemment selon l'échelle ou la personne | | |
| ☐ | Parle d'un personnage par son prénom et sa situation, plus par sa catégorie | | |

### Signes de l'échec SPENT `$` — « avec de bons choix, ça s'arrange »

| ☐ | Signe | Écran | Citation |
|---|---|---|---|
| ☐ | Cherche l'option « optimale » d'un mois comme on résout une énigme | | |
| ☐ | Parle de gagner, réussir, boucler son mois, bien jouer, score | | |
| ☐ | Attribue la difficulté du personnage à ses choix (« il n'a qu'à… », « elle gère mal ») | | |
| ☐ | Ignore les options « Hors de portée » et leurs motifs, ou les vit comme une injustice du **jeu** plutôt que comme une contrainte du personnage | | |
| ☐ | Veut rejouer « pour faire mieux » | | |
| ☐ | Lit les rappels comme une punition (« le jeu me punit ») plutôt que comme un effet | | |

### Signe d'échec inverse — fatalisme

| ☐ | Signe | Écran | Citation |
|---|---|---|---|
| ☐ | « De toute façon c'est foutu », se désengage des choix, clique sans lire | | |
| ☐ | Trouve le jeu misérabiliste, plombant | | |

### Signes de biais perçu `⇐` `⇒`

Noter **dans quel sens** le joueur perçoit le penchant, avec ses mots, et ce qui l'a
déclenché (une option, un argument, un chiffre, un personnage, un mot, l'ordre).

| ☐ | Signe | Sens perçu (ses mots) | Déclencheur / écran | Citation |
|---|---|---|---|---|
| ☐ | Dit que le jeu « pousse » vers une réponse | | | |
| ☐ | Trouve un argument caricatural ou écrit « par un adversaire » | | | |
| ☐ | Conteste un chiffre ou sa source | | | |
| ☐ | Trouve un personnage cliché, ou trop / pas assez sympathique | | | |
| ☐ | Conteste le cadrage de la question elle-même | | | |
| ☐ | Se sent jugé, culpabilisé, ou « testé » | | | |
